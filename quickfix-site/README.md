# QuickFIX Appliance Repair website

Upload the contents of this folder or the ZIP to Cloudflare Pages. This is a static site; no build step or server credentials are required. Use HTTPS and connect quickfixphx.com as a custom domain.

The canonical URL and sitemap use https://quickfixphx.com/. Verify the site in Google Search Console and submit the sitemap. Confirm business name, phone, service area and offered services with the owner. Add only verified hours, address, credentials, reviews and service areas. Search placement and indexing are not guaranteed.

The MendCue chat integration is implemented and ships disabled until the backend is provisioned with HTTPS and a real tenant. Follow [the integration runbook](../docs/quickfix-integration.md) to generate public connection settings and activate it. No Meta key belongs in this folder. The illustrated appliance is CSS. Fonts and their licenses are included.
